# docs

이 프로젝트의 근거가 되는 두 문서.

| 파일 | 내용 |
|------|------|
| `AI-활용-학습법.md` | 학습 방법론. 5단계 사이클(지도 → 구멍 → 근거 → 실물 → 출력)과 프롬프트 모음 |
| `프론트엔드-기반지식-학습맵.md` | 36개 주제. 각 주제의 학습 지도, 더 깊게 팔 부분, 접목 지점, 자료 |

## 어떻게 쓰나

| 언제 | 무엇을 보나 |
|------|------------|
| 주제를 고를 때 | 학습맵의 전체 지도 표와 티어 |
| `00-MAP.md`를 채울 때 | 학습맵의 해당 주제 **"학습 지도"** 섹션 |
| 「파고들 후보」를 적을 때 | 학습맵의 **"더 깊게 파면 좋은 부분"** |
| `05-APPLIED` 대상을 고를 때 | 학습맵의 **"접목해볼 수 있는 부분"** |
| `02-SOURCES`에서 뭘 읽을지 | 학습맵의 각 주제 **"자료"** |
| 방법이 헷갈릴 때 | 학습법 문서 |

## Word로 보고 싶다면

`md2docx.py`로 변환한다.

```bash
python3 md2docx.py <입력.md> <출력.docx>
```

pandoc·LibreOffice 없이 파이썬 표준 라이브러리만 쓴다.
제목·표·코드블록·인용·체크박스·굵게·인라인코드를 지원하며, 다른 md 문서에도 그대로 쓸 수 있다.

변환 결과물은 추적하지 않는다(`.gitignore`). **md가 원본이고 docx는 사본**이므로,
내용을 고칠 일이 있으면 항상 md를 고친다.

## 학습맵을 고칠 때

주제를 추가·삭제·재분류했다면 **`../PROGRESS.md`의 표도 같이 고친다.**
`new-topic.sh`가 그 표를 읽어서 슬러그·타입·주제명을 채우기 때문에, 안 맞으면 자동 생성이 실패한다.
