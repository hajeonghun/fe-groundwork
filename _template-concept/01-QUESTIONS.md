# {{TOPIC}} — 질문과 구멍

> **작성 주체: 🧑 나** (AI에게 절대 시키지 않는다)
> **언제:** `00-MAP.md` 직후. 그리고 학습 내내 계속 추가.
> **목적:** 내가 뭘 모르는지 드러내기. **이 프로젝트에서 가장 중요한 파일이다.**
>
> AI 답변은 항상 술술 읽혀서 막히는 감각이 사라진다.
> 그래서 **직접 설명해보다 막히는 지점**을 인위적으로 만들어야 한다. 그게 이 파일이다.

## ⚠️ 이 파일은 "단계"가 아니라 "계속 돌아오는 파일"이다

번호가 붙어 있어서 한 번 하고 끝내는 것처럼 보이지만 아니다.

```
00 → 01 → 02 → 03 → 04 → 05
      ↑     │    │    │
      └─────┴────┴────┘
        새 의문이 생길 때마다 계속 추가
```

- `02`에서 자료를 읽다가 새 의문이 생기면 → 여기에 추가
- `03`에서 원칙과 안 맞는 사례를 발견하면 → **"왜 여기선 다른가"가 새 질문** → 여기에 추가
- `04`에서 `[?막힘]` 표시한 것 → 여기에 옮겨 적기

**그래서 처음부터 완벽한 목록을 만들려고 붙잡고 있지 않는다.**
질문 3~5개가 나오면 충분하다. 그걸 들고 바로 `02`로 간다.

---

## 쓰는 방법

### 1) 자가 테스트 — `00-MAP.md`를 열어놓고 한다

이 파일만 보고 하는 게 아니다. **`00-MAP.md`를 열어놓고** 거기 적힌 항목을 하나씩 짚는다.

> `04-NOTES.md`와 반대다. 거기는 설명이 적혀 있어서 닫아야 하지만,
> `00-MAP.md`는 목차라서 오히려 봐야 한다.
> **항목 이름만 보고 내용을 못 꺼내는 것**이 여기서 찾는 구멍이다.

**진행 방법**

1. 「파고들 후보」에서 항목 **하나**를 고른다
2. 그 이름만 보고 **3~4문장으로 설명해본다** — 소리 내어, 또는 빈 메모장에
3. **막히면** 아래 "막힌 지점"에 적는다. 답을 찾기 전에 먼저 적는다
4. **술술 나오면** 넘어간다. 진짜 맞는지는 2)의 AI 심문에서 걸러진다

「전체 흐름」과 「핵심 용어」도 대상이다.
흐름은 **"순서대로 말해보기"**, 용어는 **"이 용어와 저 용어의 관계 말해보기"** 가 좋은 테스트다.
**관계에서 유독 잘 막힌다.**

소요 시간은 30분~1시간이면 충분하다. 완벽히 끝내고 넘어갈 필요 없다.

### ⚠️ "궁금한 것"과 "막힌 것"은 다르다

이 파일에서 가장 자주 어긋나는 지점이다.

| | 예 | 문제 |
|---|---|---|
| ❌ 궁금한 것 | "캐시 무효화가 궁금하다" | 정보가 없다. `02`에서 뭘 찾아야 할지 모른다 |
| ✅ 막힌 것 | "'서버가 진실이라 다시 물어봐야 한다'까지는 나왔는데, **언제** 다시 물어보는지를 설명 못 했다" | 읽어야 할 지점이 정확히 특정된다 |

**목차를 눈으로 훑으며 "이건 모르겠네" 하는 건 자가 테스트가 아니다.**
우리는 원래 모르는 것보다 **안다고 착각하는 것**에 더 잘 속는다.
그래서 **반드시 설명을 시도해야** 구멍이 드러난다.

궁금한 것도 적어도 되지만 **섹션이 다르다.**

| 섹션 | 무엇 |
|------|------|
| 막힌 지점 | 설명하려다 안 나온 것 |
| 확인이 필요한 의심 | AI 설명이 미심쩍은 것 |
| 아직 못 푼 것 | 궁금하지만 이번엔 안 다룰 것 |

궁금한 것을 「막힌 지점」에 섞으면 `02`에서 **뭘 읽어야 할지 초점이 흐려진다.**

### 2) 그다음 AI에게 심문시키기 — 순서가 중요하다

| | 찾아내는 것 |
|---|---|
| 자가 테스트 | 내가 **모른다는 걸 아는 것** |
| AI 심문 | 내가 **안다고 착각한 것** ← 더 위험한 쪽 |

**AI 심문을 먼저 하면 AI가 던지는 질문 프레임에 갇힌다.**
내 머릿속을 먼저 훑어야 "AI는 안 물었는데 나는 모르는 것"이 나온다.

```
{{TOPIC}}에 대해 나를 테스트해줘.
설명은 하지 말고, 내 답변의 허점만 지적하면서 한 번에 하나씩 질문해.
내가 틀리면 정답을 알려주지 말고 반례가 되는 상황을 제시해줘.
```

### 3) 이후 학습 내내 계속 추가한다

⚠️ **해소된 질문을 지우지 않는다.** 답을 옆에 적고 상태만 바꾼다.
나중에 다시 볼 때 "그때 몰랐던 걸 지금은 아는지"가 보이는 게 이 파일의 가치다.

## 두 섹션의 용도가 다르다

| 섹션 | 무엇을 적나 | `02-SOURCES.md`에서 |
|------|-----------|-------------------|
| **막힌 지점** | 설명을 못 하는 것 | **이해하려고** 읽는다 |
| **확인이 필요한 의심** | AI 설명이 미심쩍은 것 | **검증하려고** 읽는다 |

같은 자료를 봐도 목적이 다르다. 전자는 개념 파악, 후자는 사실 대조다.
